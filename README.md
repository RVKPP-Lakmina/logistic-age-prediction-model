# Logistic Age Prediction with NumPy, Matplotlib, and Sklearn

This project demonstrates a simple machine learning pipeline to predict age groups using Logistic Regression. It utilizes `NumPy`, `Matplotlib`, and `Scikit-learn (sklearn)` to handle data preprocessing, visualization, model training, and evaluation.

---

## 🚀 Project Overview

The goal of this project is to:

- Understand and apply logistic regression for classification tasks.
- Predict age categories based on features (e.g., income, education, etc.).
- Visualize results and insights using Matplotlib.
- Build a foundational understanding of working with NumPy arrays and sklearn pipelines.

---

## 🛠️ Technologies Used

- **Python 3.x**
- **NumPy** – for numerical operations.
- **Matplotlib** – for visualizing data and results.
- **Scikit-learn (sklearn)** – for machine learning models and preprocessing.
